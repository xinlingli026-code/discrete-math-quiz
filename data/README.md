## 题库数据格式说明

每个 `secXX.js` 导出一个纯数据对象，追加到 `window.BANK`：

```js
window.BANK.push({
  sec: "1.1",
  title: "Propositional Logic",
  titleCn: "命题逻辑",
  tips: ["中文考点提要"],
  items: [
    {
      no: 1,
      type: "命题判定",
      q: "题干（英文）",
      parts: [
        { k: "a", q: "小题题干", mode: "tf", ans: ["true"], ref: "参考答案" }
      ]
    }
  ]
});
```

`mode` 取值：`tf`（判断）/ `choice`（单选）/ `short`（填空，答案唯一时自动判分）/ `self`（主观，对照答案自评）。
完整字段与判分约定见根目录 `SCHEMA.md` 与 `README.md` 的「判分规则」一节。
